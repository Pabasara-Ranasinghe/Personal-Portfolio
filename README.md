## ✨ About

This is my personal portfolio website, designed to present my journey as a Software Engineering student and developer.

The portfolio brings together my technical skills, academic background, projects, experience, and contact information in a clean and modern interface.

It is built with a focus on:

* Modern and responsive UI
* Clean and minimal design
* Mobile-friendly navigation
* Light and dark themes
* Smooth section transitions and animations
* Interactive project presentation
* Accessible contact information
* Responsive layouts across different screen sizes

### 🎨 Modern UI

A clean, minimal, and responsive interface designed to provide a consistent experience across desktop, tablet, and mobile devices.

## 💻 Run Locally

### 1. Clone the repository

```bash
git clone https://github.com/PabasaraRanasinghe216/Personal-Portfolio.git
```

### 2. Navigate to the frontend

```bash
cd Personal-Portfolio/frontend
```

### 3. Install dependencies

```bash
npm install
```

### 4. Start the development server

```bash
npm run dev
```

The application will be available at the local Vite development URL shown in your terminal.

---

## 🚀 Deployment

The frontend is deployed using **Vercel** and connected to the GitHub repository.
